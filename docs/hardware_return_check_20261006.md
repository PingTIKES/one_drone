## 下一步顺序

1. 固定相机流与算法参数，在纹理充足、光照均匀场景进行有位置标记的缓慢返回测试，并限制转速；与本录包比较。

3. 若缓慢测试仍明显漂移，再针对相机–IMU 时间偏移、外参与 IMU 噪声/内部参数做受控对照；避免同时改多项参数。
4. 不通过放宽 INVALID 门控来掩盖定位偏差。本轮并未被门控拒绝，而是仍报告 VALID 的累计估计误差。
